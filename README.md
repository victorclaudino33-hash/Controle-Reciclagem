# Controle-Reciclagem# ♻️ Controle de Reciclagem

Uma aplicação web desenvolvida para gerenciar e monitorar processos de reciclagem de forma eficiente e intuitiva. O sistema permite o controle de materiais, registros de coletas e acompanhamento de metas ambientais.

🚀 O projeto está hospedado e pode ser acessado em: **[Controle de Reciclagem](https://controle-reciclagem.vercel.app/)**

## ✨ Funcionalidades

* **Painel de Controle (Dashboard):** Visualização rápida dos indicadores de reciclagem.
* **Cadastro de Materiais:** Registro detalhado de diferentes tipos de resíduos (plástico, papel, vidro, metal, etc.).
* **Histórico de Coletas:** Acompanhamento de volumes recolhidos, datas e destinos.
* **Controle de Acesso:** Sistema de login seguro para administradores e operadores do sistema.
* **Relatórios:** Geração de dados para análise de impacto ambiental e eficiência.
